# A-Math Best Play (รันในเครื่อง)

ไม่ต้องใช้ API key และไม่มีค่าใช้จ่าย ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

## ต้องมี
- Node.js 18 ขึ้นไป (ตรวจด้วย `node -v`)

## เริ่มใช้งาน
ในโฟลเดอร์ `amath-local` เปิด PowerShell หรือ Terminal แล้วพิมพ์
```
npm start
```
จากนั้นเปิด http://localhost:3000 ในเบราว์เซอร์

## โหมด
- **กระดานเต็ม:** คลิกช่องเพื่อวางเบี้ย ตั้งช่องพิเศษ พิมพ์ตาคู่แข่ง (เช่น `3+4=7`, `[12]-[2]=10`, `2*3=6`; `*` คือ ×, `/` คือ ÷) ตรวจกระดาน แล้วหา Best Play
- **โหมดบิงโก:** เลือกจำนวนเบี้ย 8-15 ตัว ระบบสร้างแถว 1 แถวตามจำนวนนั้น แล้วระบุเบี้ยที่อยู่บนกระดานแล้วในช่อง ช่องที่เหลือจะถูกเติมจากเบี้ยในมือ กด "หา Best Play" เพื่อหาการเรียงที่เต็มทั้งแถว

## ทดสอบ
```
npm test
```

## ข้อมูลและความเป็นส่วนตัว
- เกมที่กำลังเล่นเก็บใน localStorage ของเบราว์เซอร์นี้ รีเฟรชแล้วยังอยู่
- ปุ่มย้อนกลับ หรือ Ctrl+Z ย้อนการเปลี่ยนแปลงได้

## ปรับแต่ง
- เปลี่ยนพอร์ตด้วยตัวแปร `PORT` เช่น `$env:PORT=4000; npm start`
